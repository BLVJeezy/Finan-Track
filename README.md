# Finan Track

Een responsive financieel dashboard met React, TypeScript, Vite en Recharts.

## Starten

```bash
npm install
npm run dev
```

## Functies
- Inkomsten en uitgaven registreren
- Maandelijkse totalen en budgetoverzicht
- Transacties verwijderen
- Grafieken en categorieën
- Lokale opslag in de browser (localStorage)

**Privacy:** De voorbeeldtransacties zijn fictief. Er worden geen bankgegevens verstuurd. LocalStorage is niet geschikt voor gevoelige financiële gegevens op gedeelde apparaten. Voor synchronisatie tussen apparaten is een beveiligde backend en authenticatie nodig.
